# ZELO 2.0

**Learn. Practice. Build.**

ZELO is a beginner-friendly, gamified coding education mobile application.

## Project Goals

- Deliver an engaging, interactive coding-learning experience.
- Teach HTML, CSS, JavaScript, and React in a structured sequence.
- Provide meaningful practice, feedback, and learner progress.
- Keep lesson content version-controlled and validated.
- Enforce learning progress and rewards on the trusted backend.

## Technology Stack

- Mobile: React Native, Expo, TypeScript
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Initial platforms: Android and iOS
- Web support: Deferred

## Repository Structure

- `apps/mobile/` — Mobile application
- `apps/api/` — Backend API
- `content/curriculum/` — Version-controlled curriculum content
- `content/schemas/` — Content validation schemas
- `docs/zelo-2.0-docs/` — Original project specifications
- `scripts/` — Development and validation scripts

## Source of Truth

Review the original specifications in `docs/zelo-2.0-docs/` before implementing a feature.

If specifications conflict, document the conflict and resolve it before implementing the affected functionality.

## Development Workflow

Specify → Implement → Test → Verify → Commit → Next Feature

Do not consider a feature complete until its applicable tests and TypeScript checks have passed.
